# MyTax — คำนวณและวางแผนภาษีเงินได้บุคคลธรรมดา 2569

แอปพลิเคชันคำนวณและวางแผนลดหย่อนภาษีเงินได้บุคคลธรรมดา (ภ.ง.ด.90 / ภ.ง.ด.91) ประจำปีภาษี 2569 ออกแบบด้วยดีไซน์ **Apple Liquid Glass** (iOS 26 Style) พร้อมระบบจำลองลดหย่อนภาษีแบบ Real-time และทำงานแบบ **Offline PWA** เก็บข้อมูลในเครื่อง 100% เพื่อความเป็นส่วนตัวสูงสุด

---

## จุดเด่นของ MyTax

### 1. คำนวณภาษีตามกฎหมายไทยปี 2569 ล่าสุด
- **ครอบคลุมเงินได้ครบ 8 ประเภท (40(1) ถึง 40(8))**:
  - 40(1) เงินเดือน โบนัส
  - 40(2) ฟรีแลนซ์ รับจ้าง ค่านายหน้า เบี้ยประชุม (หักค่าใช้จ่ายร่วม 40(1) 50% สูงสุด 100,000 บาท)
  - 40(3) ค่าลิขสิทธิ์ สิทธิบัตร
  - 40(4) ดอกเบี้ย และ**เงินปันผลหุ้น พร้อมคำนวณเครดิตภาษีเงินปันผลอัตโนมัติ**
  - 40(5) ค่าเช่าทรัพย์สิน (บ้าน ที่ดิน ยานพาหนะ)
  - 40(6) วิชาชีพอิสระ (การประกอบโรคศิลปะ 60%, อื่นๆ 30%)
  - 40(7) รับเหมาก่อสร้าง (หักเหมา 60%)
  - 40(8) ธุรกิจ การค้า พาณิชย์ เกษตรกรรม (หักเหมา 60%)
- **เปรียบเทียบ 2 วิธีตามกฎหมายสรรพากร**:
  - วิธีที่ 1: อัตราก้าวหน้าขั้นบันได (0% – 35%)
  - วิธีที่ 2: 0.5% ของเงินได้พึงประเมินนอกเหนือจาก 40(1) เมื่อเกิน 1,000,000 บาท
- **คำนวณผลลัพธ์สุทธิ**: หักภาษี ณ ที่จ่าย และเครดิตภาษีเงินปันผล เพื่อสรุปว่า **"ได้คืน"** หรือ **"จ่ายเพิ่ม"** ทันที

### 2. วางแผนลดหย่อนภาษีอัจฉริยะ (Smart Tax Planning)
- **คุมเพดานกลุ่มเกษียณ 500,000 บาท**: RMF + PVD/กบข. + ประกันบำนาญ + กอช. รวมกันไม่เกิน 500,000 บาท
- **กองทุน ThaiESG เกณฑ์ใหม่**: สิทธิ์ลดหย่อนแยกต่างหากสูงสุด 300,000 บาท (ถือครอง 5 ปีนับวันชนวัน)
- **What-If Sliders**: ปรับสไลเดอร์เพื่อดูเงินภาษีที่จะประหยัดได้ทันที และผลตอบแทนจากการประหยัดภาษี (Effective ROI)
- **จัดอันดับ "ซื้ออะไรคุ้มสุด"**: แนะนำเครื่องมือลดหย่อนตามฐานภาษีสูงสุดของผู้ใช้ พร้อมบอกสิทธิ์คงเหลือ

### 3. Apple Liquid Glass Design (iOS 26 Aesthetic)
- การ์ดกระจกโปร่งแสง frosted glass พร้อม specular highlight แสงสะท้อนขอบบน
- พื้นหลัง Organic fluid gradient blobs เคลื่อนไหวช้าๆ สบายตา รองรับการเปิด/ปิด animation (prefers-reduced-motion)
- สลับธีมมืด (Dark) / สว่าง (Light) ได้อย่างลื่นไหล
- กราฟแท่งขั้นบันได (Step Chart) แสดงตำแหน่งฐานภาษีของคุณ
- ปาร์ตี้ Confetti เฉลิมฉลองเมื่อได้ภาษีคืน

### 4. ความเป็นส่วนตัวสูงสุด (100% Local Privacy & Offline PWA)
- ไม่มีการส่งข้อมูลใดๆ ออกไปยังเซิร์ฟเวอร์ภายนอก ข้อมูลทั้งหมดเก็บอยู่ใน localStorage/IndexedDB ของเครื่องคุณเท่านั้น
- รองรับการ Export / Import ข้อมูลสำรองเป็นไฟล์ JSON
- รองรับการติดตั้งแบบ PWA (Add to Home Screen) เปิดใช้งานได้ทั้งบน iOS, Android และ Desktop

## เทคโนโลยีที่ใช้ (Tech Stack)
- **Framework**: Vite + React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Liquid Glassmorphism CSS Tokens
- **Icons**: Lucide React
- **Testing**: Vitest (ทดสอบ Tax Engine ด้วยตัวอย่างและเงื่อนไขของกรมสรรพากร)
- **PWA**: vite-plugin-pwa (Service Worker + Web App Manifest)
- **CI/CD**: GitHub Actions สำหรับ Deploy ไปยัง GitHub Pages
